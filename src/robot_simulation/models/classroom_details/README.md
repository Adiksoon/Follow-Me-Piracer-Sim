# Classroom details asset

This is an original, locally authored scene prop for the PiRacer thesis simulation. The planter, stem and low-poly leaf mesh were created for this scene; no external mesh, texture or code was copied. The DAE contains simple faceted leaf blades for a stable, recognizable RGB-D shape. The pot and stem have cylinder collisions; leaf blades contribute to RGB-D rendering and are visual-only. Appearance awaits author review in Gazebo; improved VO tracking has not been verified.
