Zachowano strukturę modelu Xacro i siedem upstreamowych meshy STL. Opis został dostosowany do pakietu robot_description i ramy base_link; kamera jest oznaczona jako przybliżenie symulacyjne, nie jako pomiar fizycznego montażu. Xacro zawiera istniejący plugin Ackermann Gazebo. Nie oznacza to, że w tym repozytorium skonfigurowano lub uruchomiono scenę.
